# Bookmark Sorter — Project Site

This repository contains the public website for **Bookmark Sorter**, a Chrome extension for organizing bookmarks with user-defined rules, preview-before-apply sorting, and recovery/Undo tools.

**Live site:** https://adamflores1.github.io/bookmark-sorter-site/

## What this repository contains

This is the **website repository**, not the extension source repository.

It contains the static pages and assets used for:

- product and feature information;
- installation/release information;
- privacy disclosures;
- support information;
- terms and donation information.

The site is built with plain HTML and CSS and is published through GitHub Pages.

## Current product positioning

Bookmark Sorter is currently presented as **free to use**, with optional donations supporting development.

The public site describes features including:

- basic rule-based sorting by domain, URL, or title;
- exact destination-folder selection;
- previewing planned moves before applying them;
- stale-state protection when a bookmark changes after preview;
- optional live sorting;
- bookmark backup/export;
- supported Undo/recovery behavior;
- exact-URL duplicate inspection.

For the authoritative current behavior and availability, use the published site rather than older development notes or archived planning documents.

## Privacy

Bookmark processing is designed to stay in the browser. The published privacy policy describes what the extension stores locally, what Chrome permissions are used, and what information may be handled separately when a user contacts support or visits an external donation provider.

See: [Privacy policy](https://adamflores1.github.io/bookmark-sorter-site/privacy.html)

## Repository scope

The extension implementation, internal development tooling, licensing experiments, and historical build material are **not** part of this repository. This repository should therefore not be treated as the complete Bookmark Sorter codebase.
