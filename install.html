Bookmark Sorter

Install and activate

Bookmark Sorter runs in desktop Google Chrome. The extension supports Chrome 99 or later. Keep Chrome updated for security and compatibility.

Start with Free

The public store listing is not open. Downloads will be linked here when the extension is released.

  1. Install Bookmark Sorter from its Chrome Web Store listing.
  2. Open Settings, choose a rule and an exact destination folder, then save it.
  3. Export a bookmark backup before your first cleanup.
  4. Open the popup, select the rules, and run Preview. Review the exact moves before Sort.

Live sorting is off until you enable it. Free can use up to three selected basic rules for live sorting.

Activate Pro

When checkout opens, buy the €9.99 one-time Pro license through Dodo Payments. The planned automated delivery sends your key by email. There is no subscription.

  1. Open the extension's Settings and select License.
  2. Paste your license key and choose Activate.
  3. Grant the requested permission for the licensing host to complete activation.

Activation requires internet access. A license allows up to three active installations. To move to another installation, deactivate an existing one in Settings → License first. Removing the extension alone does not release the provider's slot.

If you lose a key or an installation, use the support instructions. Do not send a full key in a support email.
