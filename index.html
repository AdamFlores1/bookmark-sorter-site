Chrome extension

Make sense of your bookmarks.

Create rules for the sites and pages you save. See exactly what will move before you sort, and use Undo when you need to put things back.

Release information ↗Free to use. Optional donations support development.

Decide what moves.

Bookmark Sorter keeps the review step in your hands. Live sorting is optional and starts off by default.

01

Write a rule

Match a bookmark by its domain, URL or title and choose an exact destination folder.

02

Preview the moves

Review the planned changes before applying them. If a bookmark changes after preview, the sorter skips it.

03

Sort with a way back

Apply the plan when you are ready. An Undo journal helps reverse supported moves. Keep a backup for extra protection.

Your rules and your folders

The extension is free to use, with no account required.

Sort when you choose

Unlimited basic single-condition rules for manual sorting.

  • Match domains, URLs or bookmark titles
  • Preview exact moves before Apply
  • Choose folders and control rule order
  • Import and export your rule configuration

Keep changes manageable

Optional automation and recovery tools.

  • Up to three selected rules for live auto-sort
  • Export an HTML bookmark backup
  • Undo supported sorting operations
  • Inspect exact-URL duplicate copies

Duplicate inspection does not delete bookmarks. Remove individual copies in Chrome's bookmark manager.

Bookmark processing stays in your browser.

Bookmark titles, URLs, folders, rules, previews and Undo history are processed locally. The extension uses bookmarks and storage permissions and makes no background network requests.

There are no accounts, advertising or analytics in the extension. Optional donation links open an external website only when you choose them.
